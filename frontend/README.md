# Clickort Frontend ⚡

Клиентская часть для соревновательной платформы кликинга в реальном времени.

## Стек технологий
* **React 18** + **TypeScript**
* **Vite** (сборщик)
* **WebSockets** (нативное двустороннее соединение с бэкендом)
* **Lucide React** (иконки)
* **Canvas Confetti** (эффекты победы)
* **Web Audio API** (встроенные синтезированные звуки кликов и сигналов)

## Архитектура и функционал
1. **Экран входа / Регистрация**: Ввод никнейма (до 20 символов), подключение к `ws://localhost:8081/ws`.
2. **Экран Лобби**: Отображение участников комнаты в реальном времени. Кнопка «Я ГОТОВ!» активируется при наборе от 5 участников.
3. **Обратный отсчет (3.. 2.. 1.. GO!)**: Запускается, как только все участники лобби подтвердили готовность.
4. **Игровой раунд (60 секунд)**:
   * **Optimistic UI**: Локальный счётчик прибавляет клики мгновенно с нулевой задержкой.
   * **Высокая скорость (CPS)**: Измерение кликов в секунду в реальном времени.
   * **Live Leaderboard**: Список лидеров в реальном времени из Redis ZSet.
   * **Поддержка Пробела**: Клики можно делать мышкой, тапом или клавишей `Пробел`.
5. **Экран победителя**: Подиум топ-3, конфетти, личные результаты и кнопка возврата в лобби.

## Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### 3. Сборка для продакшена
```bash
npm run build
```

## Настройка WebSocket
По умолчанию клиент подключается к `ws://localhost:8081/ws`. 
Для изменения адреса (например, на Render.com) создайте файл `.env`:
```env
VITE_WS_URL=wss://your-backend.onrender.com/ws
```
